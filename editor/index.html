Logga in för att publicera

Editorn sparar direkt i GitHub-repot med en personlig nyckel. Nyckeln sparas bara i den här webbläsaren.

  1. Gå till GitHub → Fine-grained token.
  2. Ge den ett namn, t.ex. Fritidscenter-editor, och välj en giltighetstid.
  3. Resource owner: ägaren av repot. Repository access: Only select repositories → repot.
  4. Permissions → Repository → Contents: Read and write. Inget annat behövs.
  5. Klicka Generate token och klistra in den här.
